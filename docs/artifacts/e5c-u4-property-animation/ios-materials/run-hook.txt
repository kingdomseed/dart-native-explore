Cases: explicit clear, empty SCNRenderer load, actual current fragment, original
late multiply (normalizes exactly one occurrence), no late multiply, explicit
premultiplied reference. All candidate scenes/materials/cameras are private and
separate. The original live material/geometry/texture/scene is never mutated.

Synthetic isolation inputs: the copied material's diffuse image is replaced by
white; geometry is SCNPlane2x2; camera is orthographic at native Z3; no lights,
HDR, exposure adaptation or image effects. Constant ordinary source shading,
surface factor modifier, actual KVC factor and BLEND flags remain. This is a
shader/compositing diagnostic, not proof of image UVs, PBR, camera rendering,
animation interpolation, performance or complete U4.

The probe deliberately waits synchronously for its private command buffers and
retains every scene/renderer/texture/buffer. It is never production rendering.
Each output is compared against the measured empty-scene baseline, not merely
the requested clear. Parent must interpret expectedStraightAlphaRGBA versus
expectedDoublePremultipliedRGBA and inspect outer patches/GPU status. No PASS
is encoded. Exact alpha readback includes destination alpha 1; this does not
test partial destination coverage (already separate sprite evidence).
