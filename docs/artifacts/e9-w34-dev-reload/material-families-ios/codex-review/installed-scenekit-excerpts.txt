95:  
96:  Shader modifiers can be used to tweak SceneKit rendering by adding custom code at the following entry points:
97:      1. vertex   (SCNShaderModifierEntryPointGeometry)
98:      2. surface  (SCNShaderModifierEntryPointSurface)
99:      3. lighting (SCNShaderModifierEntryPointLightingModel)
100:      4. fragment (SCNShaderModifierEntryPointFragment)
101:  See below for a detailed explanation of these entry points and the context they provide.
102:  
103:  Shader modifiers can be written in either GLSL or the Metal Shading Language. Metal shaders won't run on iOS 8 and macOS 10.10 or earlier.
104:  
105:  The structure of a shader modifier is:
139:  The `#pragma body` directive
140:      Is only needed if you declared functions that must not be included in the shader code itself.
141:  
142:  The `#pragma transparent` directive
143:      Forces the rendering to be blended using the following equation:
144:          _output.color.rgb + (1 - _output.color.a) * dst.rgb;
145:      where `dst` represents the current fragment color. The rgb components must be premultiplied.
146:  
147:  The `#pragma opaque` directive
148:      Forces the rendering to be opaque. It then ignores the alpha component of the fragment.

154:          | #pragma varyings
155:          | half3 myVec;

157:      2. Then write the varying values from the vertex shader (geometry shader modifier):
158:  
159:          Metal Shading Language
160:          | #pragma body
161:          | out.myVec = _geometry.normal.xyz * 0.5h + 0.5h;

163:      3. Finally read the varying values from the fragment shader (surface and/or fragment shader modifier):
164:
